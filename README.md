"# poppoethiopia" 
Build a premium, modern, responsive recruitment/agency website for a Poppo Live agency using:

- Vite
- React
- JavaScript
- CSS
- No TypeScript
- No Tailwind CSS
- No backend
- No database

The purpose of this website is to attract new hosts/creators and encourage them to join our Poppo Live agency.

IMPORTANT:
This is a recruitment/agency landing website, NOT a recreation of the Poppo Live application itself.

Do not copy Poppo Live's source code, exact layout, copyrighted graphics, or proprietary assets.
Create an original design that has a similar modern live-streaming/social-media atmosphere.

==================================================
BRAND / PURPOSE
==================================================

Create a professional agency website that communicates:

"Join Poppo Live. Become a creator. Build your audience. Earn from your live streams."

The website should feel trustworthy, exciting, premium, youthful and modern.

Primary goal:
Get visitors to click "Join Now" / "Become a Host" and contact the agency.

Secondary goals:
- Explain how becoming a host works
- Explain potential earning opportunities carefully without making unrealistic income guarantees
- Show benefits of joining the agency
- Answer common questions
- Provide contact methods
- Direct users to the appropriate official Poppo Live registration/download page

Use placeholders for information that the client can replace later.
